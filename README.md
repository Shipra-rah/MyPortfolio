**🌐 [Live Demo](https://shipraportfolio.vercel.app/)**

## ✨ Features

- 🎬 **Smooth Animations** - Powered by GSAP, Framer Motion, and React Type Animation
- 🎮 **3D Graphics** - Three.js integration with React Three Fiber
- 📱 **Fully Responsive** - Mobile-first design with Tailwind CSS
- ⚡ **High Performance** - Optimized builds with Vite
- 🎯 **Fast Development** - HMR (Hot Module Replacement) for instant feedback
- 🌈 **Modern UI** - Clean, professional design with premium animations
- 🔄 **Client-Side Routing** - Smooth navigation with React Router

## 📦 Installation

### Prerequisites
- Node.js 16+ or higher
- npm or yarn package manager

### Setup

```bash
# Clone the repository
git clone https://github.com/Shipra-rah/MyPortfolio.git
cd MyPortfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview

# Run linting
npm run lint
```

The development server will typically run at `http://localhost:5173`

## 🚀 Quick Start Guide

1. **Start Development Server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser

2. **Make Changes**
   - Edit files in the `src/` directory
   - Changes will hot-reload automatically

3. **Build for Production**
   ```bash
   npm run build
   ```
   Creates optimized production build in `dist/`

4. **Preview Production Build**
   ```bash
   npm run preview
   ```
